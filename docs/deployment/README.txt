deployment-guide.md — текст с командами для копирования.

Для существующего сервера не повторяйте установку с начала.
Скрипт копирования запускается на целевом сервере под root по разделу 14.
Пути рассчитаны на развёртывание, описанное в документе.
Секретных значений в комплекте нет; полученные резервные копии содержат секреты,
поэтому их нельзя отправлять в GitHub или общедоступный чат.
Расписание и полный Telegram-режим требуют отдельных действий на сервере.
